About

Jordan Parker is a beginner web developer who enjoys learning how the web works by building small projects and documenting the process along the way. Jordan states, I started learning HTML because I wanted to understand how websites are actually built. Since then, Jordan has focused on learning the fundamentals of semantic structure, accessibility, and writing clean, organized markup.

My First HTML Page

August 20, 2026

<h1>Hello World</h1>
<p>This is my first web page.</p>

Building my first HTML page helped me understand how individual elements work together to create the structure of a website. I learned how headings, paragraphs, links, and other semantic elements give content meaning and organization, and seeing the page render in a browser made the connection between the code I wrote and the final result much clearer.

Why Semantic HTML Matters

August 22, 2026

Semantic HTML matters because it gives meaning to the different parts of a web page instead of simply controlling how content looks. Using the right elements for headings, navigation, articles, contact information, and other content can make a page easier for developers to understand, while also helping browsers and assistive technologies interpret the structure more accurately.

Learning Through Mistakes

August 24, 2026

Learning web development has taught me that mistakes are a normal part of the process. A missing closing tag, incorrect nesting, or the wrong semantic element can cause problems, but finding and fixing those issues helps me understand HTML more deeply. Each mistake gives me a chance to slow down, review my code, and become more confident in solving problems on my own.
