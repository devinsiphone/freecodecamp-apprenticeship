Beginner Developer Reference

This reference page is designed to help beginner web developers review a few useful HTML concepts and see how specialized semantic elements can give content clearer meaning and structure.

Our website requires Internet Explorer 11 to work properly.

How Do You Display Mathematical Equations in HTML?

The superscript element is used to display a piece of text as a superscript. A superscript is a symbol or letter printed above the normal line of text.

Here is an example using the superscript element to illustrate exponents:

HTML : <p>x<sup>2</sup> + y<sup>2</sup> = z<sup>2</sup></p>

Output : x2 + y2 = z2

It is important to note that the superscript element should only be used for typographical reasons. If you want to style a piece of text with a raised baseline, then you should use CSS instead of the superscript element.

How Do You Display Chemical Formulas in HTML?

To represent chemical formulas inside HTML, you would use the subscript element. This element uses a subscript which displays a lowered baseline using smaller text.

Here is an example of using the subscript element to show the chemical representation for carbon dioxide:

HTML : <p>CO<sub>2</sub></p>

Output : CO2

The number two is wrapped inside sub tags to illustrate that the character should be a subscript.

Common use cases for the subscript element include chemical formulas, footnotes, and variable subscripts.

How Do You Represent Computer Code in HTML?

The inline code element is used to represent short snippets of code inside text. Common use cases for the code element would be for technical articles and documentation pages.

Here is an example of using the code element to show an HTML code snippet:

HTML : 

<h1>Hello World</h1>
<p>My first web page.</p>

Output :

Hello World

My first web page.

The <p> element is used to define a paragraph in HTML.

What Is the Ruby Element Used For?

The ruby element represents small text shown above or below the main text. It is typically used to show the pronunciation of East Asian characters. Here is a ruby element example:

HTML : <ruby> 明日 <rp>(</rp><rt>Ashita</rt><rp>)</rp></ruby>

Output : 明日 ( Ashita )

What Is the U Element Used For?

The unarticulated annotation element, or u element for short, is used to represent inline text that has non-textual annotation applied.

Here is an example of using the u element to highlight various spelling errors:

HTML : The word <u>accomodate</u> is misspelled.

Output : The word accomodate is misspelled.
